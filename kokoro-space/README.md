# Kokoro TTS API

OpenAI-compatible Kokoro TTS endpoint.

## Endpoints

- `POST /v1/audio/speech` — OpenAI-compatible TTS
- `POST /tts` — Custom TTS
- `GET /health` — Health check
- `GET /v1/audio/voices` — List voices
